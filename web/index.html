Times are predicted from each bus's live position and current delay, not the timetable. Rows marked timetable have no bus assigned yet, so those are scheduled times only.

Live positions need a free key

Stops, the route line and timetable positions work with no setup. Real GPS positions come from the National Transport Authority's GTFS‑Realtime feed, which requires a free API key.

  1. Register at developer.nationaltransport.ie
  2. Subscribe to the GTFS‑Realtime product and copy your primary key.
  3. Put it in a file called .nta_key next to server.py, or export NTA_API_KEY, then restart the server.

The key is only ever read by the local Python server — it is never sent to the browser.

Data sources

  • Schedule & stops: TFI GTFS feed
  • Live vehicles: NTA GTFS‑Realtime Vehicles + TripUpdates
  • Map tiles: OpenStreetMap contributors
